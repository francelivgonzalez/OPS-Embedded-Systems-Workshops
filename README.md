# OPS Embedded Systems Workshops

Arduino Nano projects I developed and used to teach introductory circuitry, electronics, and microcontroller programming through OPS workshops.

## Workshop Projects

### 01 - [Night Light](01-Night-Light/)
Uses a photoresistor to automatically turn an LED on or off based on surrounding light.

### 02 - [Light Theremin](02-Light-Theremin/)
Changes the pitch of a buzzer based on light intensity.

### 03 - [IR Tripwire Alarm](03-IR-Tripwire-Alarm/)
Detects interruptions in an infrared beam and activates an LED and buzzer alarm.

### 04 - [Simon Says](04-Simon-Says/)
A memory game where users repeat LED sequences using push buttons.

## About the Projects

All four projects use Arduino C++ and the Arduino Nano. Each workshop introduced students to basic circuit assembly, electronic components, and microcontroller programming.

The sketches and circuit diagrams in this repository were reconstructed from the original workshop projects for documentation and reference.
