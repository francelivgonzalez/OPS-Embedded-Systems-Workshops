# OPS-Embedded-Systems-Workshops

Arduino Nano embedded systems projects developed, programmed, and tested for OPS workshops to teach students introductory circuitry, electronics, and microcontroller programming.



\## Workshop Projects



These are four Arduino Nano projects I developed, programmed, and used to teach introductory circuitry and microcontroller programming through OPS workshops.



| Project | Description |

|---|---|

| \[01 - Night-Light](01-Night-Light/) | Uses a photoresistor to automatically control an LED. |

| \[02 - Light Theremin](02-Light-Theremin/) | Changes speaker pitch based on surrounding light. |

| \[03 - IR Tripwire Alarm](03-IR-Tripwire-Alarm/) | Uses an infrared beam to detect interruptions and activate an alarm. |

| \[04 - Simon Says](04-Simon-Says/) | Memory game using LED sequences and push buttons. |



All four projects use Arduino C++ and the Arduino Nano. The sketches in this repository were reconstructed from the original workshop projects.
